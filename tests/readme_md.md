# Тесты проекта Osialmaty Bot

Эта папка содержит тесты для различных компонентов проекта.

## Запуск тестов

### Тест валидации комментариев в боте
```bash
cd tests
python test_bot_comment_validation.py
```

### Тест ограничения длины комментариев в базе данных
```bash
cd tests
python test_review_comment_length.py
```

## Описание тестов

### `test_bot_comment_validation.py`
Тестирует валидацию длины комментариев на уровне бота:
- Комментарии в пределах лимита (≤500 символов) принимаются
- Комментарии длиннее лимита (>500 символов) отклоняются
- Пустые комментарии (пропуск) принимаются
- Проверка граничных случаев (500 и 501 символ)

### `test_review_comment_length.py`
Тестирует ограничения базы данных для комментариев:
- Создает тестовую базу данных в памяти
- Проверяет сохранение комментариев в пределах лимита
- Проверяет отклонение комментариев длиннее лимита
- Использует SQLite для быстрого тестирования
