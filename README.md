# ОСИ Алматы - Бот для поиска исполнителей

Telegram-бот для помощи в поиске исполнителей различных услуг в Алматы. Включает поиск по категориям, геолокации, систему отзывов и веб-админку для управления.

## 🚀 Возможности

### Для пользователей:
- 🔍 Поиск исполнителей по ключевым словам
- 📁 Просмотр по категориям (с иерархией)
- 📍 Фильтрация по региону/городу
- ⭐ Система отзывов и рейтингов
- 📸 Просмотр фото работ исполнителей
- 📞 Быстрый доступ к контактам

### Для администраторов:
- 🎛 Веб-админка для управления всем контентом
- 👥 Управление исполнителями, категориями, регионами
- 📊 Статистика поисковых запросов
- ✅ Модерация отзывов
- ⭐ Управление премиум-размещением

## 📋 Требования

- Python 3.11+
- PostgreSQL 13+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## 🛠 Установка

### 1. Клонирование и настройка окружения

```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка PostgreSQL

```bash
# Создайте базу данных
createdb osialmatybot

# Или через psql:
psql -U postgres
CREATE DATABASE osialmatybot;
\q
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
# Скопируйте example файл
cp .env.example .env
```

Отредактируйте `.env` и заполните:

```env
# Telegram Bot
BOT_TOKEN=your_bot_token_from_botfather

# Database
DATABASE_URL=postgresql+asyncpg://username:password@localhost:5432/osialmatybot

# Admin Panel
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your_secure_password
ADMIN_SECRET_KEY=your_random_secret_key_here

# App Settings
DEBUG=False
PHOTOS_DIR=storage/photos/contractors
```

### 4. Применение миграций

```bash
# Создайте первую миграцию
alembic revision --autogenerate -m "Initial migration"

# Примените миграции
alembic upgrade head
```

## 🚀 Запуск

### Вариант 1: Polling (для разработки)

**Запуск бота:**
```bash
python main.py
```

**Запуск админ-панели** (в отдельном терминале):
```bash
python admin_run.py
```

Админка: http://localhost:8000/admin

### Вариант 2: Webhook (для продакшена)

Настройте `.env`:
```env
USE_WEBHOOK=True
WEBHOOK_HOST=https://yourdomain.com
WEBHOOK_SECRET=your_secret_token
```

**Запуск объединенного приложения:**
```bash
python app_combined.py
# или
python main_webhook.py
```

Бот и админка в одном приложении: http://localhost:8000/admin

**Подробнее:** [WEBHOOK.md](WEBHOOK.md)

## 💡 Первые шаги

### 1. Добавьте регионы

Зайдите в админку (http://localhost:8000/admin) и добавьте регионы, например:
- Москва
- Санкт-Петербург
- Казань
- и т.д.

### 2. Создайте категории

Добавьте категории услуг с иконками (emoji):
- 🚚 Вывоз мусора
- 🔧 Ремонт
- 🏗 Строительство
- 💼 Услуги
- и т.д.

Можно создавать подкатегории через поле "Родительская категория".

### 3. Добавьте исполнителей

Создайте исполнителей с указанием:
- Название
- Описание
- Телефон
- Регион
- Категории (можно выбрать несколько)

### 4. Протестируйте бота

Откройте бота в Telegram и проверьте:
- Выбор региона при первом запуске
- Поиск по ключевым словам
- Просмотр категорий
- Оставление отзывов

## 🔧 Управление премиум-размещением

В админке для исполнителя установите:
- `is_premium = True`
- `premium_until = дата окончания`

Премиум исполнители показываются первыми в результатах поиска.

## 📊 Статистика

Бот автоматически логирует:
- Поисковые запросы пользователей
- Просмотры карточек исполнителей
- Активность пользователей

Данные доступны в админке в разделе "Логи поиска".

## 🐛 Отладка

### Включение debug режима

В `.env`:
```env
DEBUG=True
```

Это включит:
- Подробное логирование SQL запросов
- Более детальные логи бота

### Проверка БД

```bash
# Проверка соединения
alembic current

# Просмотр истории миграций
alembic history

# Откат последней миграции
alembic downgrade -1
```

## 🔐 Безопасность

1. **Никогда не коммитьте `.env` файл!**
2. Используйте сильные пароли для `ADMIN_PASSWORD`
3. Генерируйте случайный `ADMIN_SECRET_KEY`:
   ```python
   import secrets
   print(secrets.token_urlsafe(32))
   ```
4. В продакшене используйте HTTPS для админки

## 🔐 Контроль доступа

Бот поддерживает 3 режима доступа:

1. **Open** - доступ для всех
2. **Whitelist** - только для одобренных администратором
3. **Invite Only** - только по токену приглашения

Настройка в `.env`:
```env
ACCESS_MODE=whitelist
ADMIN_TELEGRAM_IDS=your_telegram_id
INVITE_TOKEN=secret_token_here
```

Подробнее: [ACCESS_CONTROL.md](ACCESS_CONTROL.md)
